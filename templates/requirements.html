1. Classroom Data

Physical Assets

Contains details about each classroom, lecture hall, and lab on campus.

ColumnMeaning
room_idUnique identifier (e.g. R101, B204)
buildingBlock name (e.g. Academic Block A)
floorFloor number (1, 2, 3)
capacityMaximum seats available (e.g. 75)
room_typeClassroom, Seminar Hall, Lab
projector_availableYes or No
lab_availableYes or No (computers/desks)
availableOperational status (Yes/No)

2. Timetable Data

Schedule

Maps classes, faculty, departments, and time periods to rooms.

ColumnMeaning
dateDate of the class (YYYY-MM-DD)
dayMonday, Tuesday, Wednesday...
time_slotPeriod (e.g. P1: 09:00-10:00)
departmentCSE, AIDS, IT, ECE, EEE
yearStudent batch (1, 2, 3, 4)
sectionA, B, C
subjectCourse title / Subject name
facultyAssigned professor / instructor
room_idCurrently scheduled classroom

3. Attendance Data

Actual Usage

Records actual student turnout versus registered students.

ColumnMeaning
dateSession date
departmentDepartment
yearStudent Year
sectionSection
subjectCourse title
expected_studentsTotal registered students (e.g. 70)
actual_studentsActual attendees present (e.g. 58)
room_idRoom where class was conducted

Data Privacy & Partial Uploads

Privacy Protected: Student names, register numbers, and personal details are strictly excluded. The system relies entirely on aggregated section attendance counts.
Partial Data Support: If attendance or timetable data is partially missing, the system automatically uses standard median values and allows uploading individual files without breaking.
